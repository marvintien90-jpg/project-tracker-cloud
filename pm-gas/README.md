# 專案管理員（Google Apps Script 版）

全新的多部門事項追蹤系統。資料存在你自己的 Google 試算表，網頁由 Google Apps Script 提供，
不會休眠、不需要伺服器，手機打開網址就能用。

目前完成：**第 1 步 核心骨架**

- 事項：新增、編輯、刪除，設定部門、負責人、期限、優先、狀態、下次追蹤日
- 清單自動排序：未完成 → 逾期 → 優先度高 → 期限近
- 依狀態、部門篩選，關鍵字搜尋，頂部顯示未完成／逾期／3 天內到期數量
- 勾選多筆後批次改狀態（之後第 3 步會在這裡加「發佈」）
- 補充說明與所有修改都寫進「追蹤紀錄」
- 人員（姓名、部門、Email、LINE ID）與部門管理；部門改名會同步到事項與人員

後續：第 2 步 AI 自動解析會議記錄 → 第 3 步 勾選即發佈（Email，之後 LINE）→ 第 4 步 定時再追蹤。

## 安裝（約 5 分鐘，只需做一次）

1. 在 Google 雲端硬碟新建一份 **Google 試算表**，命名為「專案管理員」。
2. 試算表選單 **擴充功能 → Apps Script**，開啟編輯器。
3. 把 `Code.gs` 的內容整份貼進編輯器裡的 `程式碼.gs`（取代原本內容）。
4. 左側「檔案」旁按 **＋ → HTML**，檔名輸入 `Index`，把 `Index.html` 的內容整份貼進去。
5. 左側齒輪 **專案設定**：時區選「(GMT+08:00) 台北」。
6. 回到編輯器，上方函式選單選 `setup`，按 **執行**，依畫面授權（選你的帳號 → 進階 → 前往專案 → 允許）。
   試算表會多出「部門、人員、事項、追蹤紀錄」四個分頁，並放好 14 個預設部門。
7. 右上 **部署 → 新增部署作業** → 類型選「網頁應用程式」：
   - 執行身分：**我**
   - 誰可以存取：**只有我自己**
   按「部署」，複製「網頁應用程式網址」。
8. 用手機開這個網址，加到主畫面，就像 App 一樣使用。

## 更新程式

貼上新版程式後：**部署 → 管理部署作業 → 編輯（鉛筆）→ 版本選「新版本」→ 部署**。網址不變。

## 資料結構

| 分頁 | 欄位 |
| --- | --- |
| 部門 | id, name, sort |
| 人員 | id, name, dept, email, line_id, active |
| 事項 | id, title, detail, dept, owner(人員 id), priority, due, status, note, selected, source, next_followup, created_at, updated_at |
| 追蹤紀錄 | id, item_id, at, action, content |

所有欄位都以純文字儲存。可以直接在試算表裡看或匯出，但請不要更改第一列欄位名稱。
